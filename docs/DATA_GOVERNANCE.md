# Data governance — READ BEFORE RELEASE

All private Cañete point coordinates, 250 m cells with registered-site flags, private 50 m cell labels, per-cell RF rankings, and derived plots are **not included in this public package**. Their distribution requires explicit review by the research team and relevant rights holders/heritage-data custodians.

The separate PRIVATE_COLAB_DATA archive is only for internal scientific review and controlled use. It contains sensitive gridded location indicators. Never upload it to GitHub or Zenodo. This archive is not a publicly safe research dataset.

For publicly distributed hands-on exercises, use the synthetic dataset generated in the notebook until a release protocol for empirical materials has been agreed upon. No independent field-validation sites enter RF training in the supplied 250 m dataset.
