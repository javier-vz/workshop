# Fictional dataset

Every CSV here is generated by the **synthetic** Notebook 2 exercise; coordinates do not refer to real archaeology. The notebooks run independently in demo mode without downloading these files. The Notebook 3 fixture is regenerated from Notebook 2 during release tests.

`nb2_nodes_SYNTHETIC.csv`: candidate nodes.  
`nb2_edges_SYNTHETIC.csv`: route metrics for each scenario.  
`nb2_route_cells_SYNTHETIC.csv`: grid cells along simulated least-cost routes.
